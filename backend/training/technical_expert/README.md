# Technical Expert evaluation

This first locked synthetic case measures specification coverage, a 10+ row
compliance matrix, methodology depth, numeric fidelity, evidence gaps, and
unsupported compliance claims.

Run from `backend/`:

```bash
.venv/bin/python scripts/evaluate_technical_expert.py
.venv/bin/python scripts/evaluate_technical_expert.py --live
```

Real tender cases must be anonymised and procurement-expert reviewed before
they enter this dataset.
