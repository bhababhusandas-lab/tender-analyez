# Finance & Accounts evaluation

The locked synthetic case measures BOQ depth, exact arithmetic, GST, EMD/PBG,
payment timing, working-capital risk, and unsupported commercial assumptions.

```bash
.venv/bin/python scripts/evaluate_finance_accounts.py
.venv/bin/python scripts/evaluate_finance_accounts.py --live
```

All real costs and financial statements require authorised human review.
