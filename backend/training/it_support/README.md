# IT Support evaluation

This locked synthetic incident tests evidence-based diagnosis, deadline-aware recovery, secure DSC handling, escalation, and prevention for a government portal upload failure.

```bash
.venv/bin/python scripts/evaluate_it_support.py
.venv/bin/python scripts/evaluate_it_support.py --live
```

The scenario is synthetic. Never place real passwords, OTPs, DSC PINs, private keys, or production bid files in this dataset.
