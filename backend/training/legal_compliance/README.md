# Legal & Compliance evaluation

The locked synthetic case measures clause coverage, exact financial exposure,
missing-clause discipline, usable pre-bid queries, and unsupported protections.

```bash
.venv/bin/python scripts/evaluate_legal_compliance.py
.venv/bin/python scripts/evaluate_legal_compliance.py --live
```

This is a regression tool, not legal advice. A qualified Indian procurement
lawyer must review real cases and approve training examples.
